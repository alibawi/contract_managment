# ENKI ERP — نموذج إدارة العقود (Clickable Mock)

نموذج تفاعلي لوحدة **إدارة العقود** بواجهة ENKI ERP (عربي، من اليمين لليسار). جميع البيانات تجريبية وتُحفظ في متصفحك (localStorage) ويمكن إعادة تعيينها من قائمة المستخدم.

## التشغيل

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # المخرجات في dist/ وتعمل من أي استضافة ثابتة
npm run check    # فحص سلامة البيانات التجريبية
```

## حالة التنفيذ
الأساس (الهيكل، الأدوار، التاريخ التجريبي، مكتبة المكوّنات، المخزن، البيانات المشتركة، فحص النظام) مكتمل. الوحدات تُبنى بالترتيب في `docs/roadmap.md`.

## أدوات العرض
- **الدور:** من قائمة المستخدم أعلى اليسار؛ يغيّر الأزرار والقوائم.
- **اليوم التجريبي:** من الشريط العلوي لتجربة الانتهاء والتنبيهات والتأخر والتجديد.
- **محاكاة خطأ الخادم / إعادة التعيين:** من قائمة المستخدم.
